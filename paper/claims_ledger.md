# Claims and evidence ledger

This ledger connects the paper's quantitative claims with their primary sources and the instruments available in the repository. The measurements are **ours as reported** in the submitted manuscript, transcribed here for comparison. A runnable instrument describes what the code can measure; it is not evidence that the printed benchmark numbers have been regenerated by the bundled local checks. The route by which our official-data run archives enter the repository and rebuild the tables is in [docs/RUN_ARCHIVES.md](../docs/RUN_ARCHIVES.md); their status is in [docs/STATUS.md](../docs/STATUS.md).

| Label | Meaning |
|---|---|
| **ours as reported** | A measurement or empirical diagnostic we print in the submitted manuscript |
| **derived / arithmetic-checked** | A calculation from stated constants or reported inputs; checks establish the calculation, not empirical provenance |
| **analytical sensitivity** | A scenario, fitted-law calculation, sample-size rescaling or power model under stated assumptions |
| **implemented / rerunnable** | The package has an instrument that produces this kind of quantity in a completed run |
| **software-tested** | A recorded test checks implementation behavior on specified fixtures; see the actual [validation record](../docs/VALIDATION.md) |
| **outside packaged runner** | A reported experiment or comparator whose end-to-end instrument is not included in the nine-route runner |

Numeric values live in [`reported_results.json`](reported_results.json). [`sources.json`](sources.json) supplies exact PDF identities and page-level provenance. All run paths below refer to a completed run directory. No row asserts fresh reproduction of the paper's benchmark measurements.

## C. Practical review commands

```bash
# Source PDF identity, page provenance, and deterministic summary rendering
python -B scripts/render_paper_results.py --check
python -B scripts/render_reported_results.py --check

# Registered constants and selected arithmetic identities
python -B scripts/check_paper_constants.py

# Source-package checks; current source identity is compared with the recorded evidence
python -B scripts/source_fingerprint.py
python -B scripts/release_audit.py --root . --profile public --strict

# Software tests in an environment with the declared dependencies
python -B -m unittest discover -s tests -v
```

The commands report their actual counts and outcomes. [VALIDATION.json](../docs/VALIDATION.json) records the evidence environment and source identities; historical raw records are retained. For a completed run, use the [results/replay guide](../docs/RESULTS.md) to validate hashes, recompute statistics and execute checkpoints. Comparison classifications such as `exact` and `interval` are descriptive numerical agreements; they do not establish benchmark replication, historical provenance or conditional statistical guarantees.
